# live/ — working-code snapshot

A source-only snapshot of the s2path research repo, kept here to version-track the
working code alongside the blog. **Code only**: `.py` / `.sh` / `.ps1`, directory
structure preserved. Excluded by design: data, model weights, checkpoints (`.pt`),
captures (`.npz`), figures, virtualenvs, caches, and result/pre-registration notes.

Scope of this mirror: the already-published tracks (the Gemma-2 attention
weight-space map and the polysemanticity/regime-mixing census) plus the supporting
capacity-ledger code (footprints, packing, reader sufficiency, continual-learning
protection, quantization). Two in-progress lines of work are intentionally held back
until their write-ups are out: the mechanism study (why crowding protects) and the
cross-scale study. They will be added here when published.
